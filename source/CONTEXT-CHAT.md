# 普通聊天上下文（共同源码 v1.39）

从本版开始，成功完成的聊天自动用 Windows 当前用户 DPAPI 加密保存在本机。GPT 与 DeepSeek 各保存自己的会话，长期记忆仍共用；旧版未保存的聊天不能补回。

## 使用

- 退出后重新启动同一版本，打开聊天即可继续当前话题。
- 「新对话」归档当前完整会话并开始空白会话，保留长期记忆。
- 聊天窗口默认显示最近 80 条，顶部「查看更早的聊天」加载更早原文。
- 「记忆」可查看、添加、删除自动整理的记忆，以及清空当前版本的聊天记录和旧会话归档。删除长期记忆不会删除聊天原文；清空聊天不会删除长期记忆。
- 记忆包括明确喜好、个人事件和交流偏好；隐含推测带「待确认」标记。记录不是人格诊断，可以随时纠正。明确遗忘会阻止同样依据被后台重新写入。

## 上下文与维护

发送时使用最近 20 条消息（文字预算 24,000 字符）、最多 6,000 字摘要和最多 8,000 字较早片段。未进入摘要的消息优先补入，再检索相关原话；上下文仍然有上限，缺失事实必须澄清，不能保证任意长度对话的每个细节都能准确回忆。

成功回复先显示、保存和配音，再在后台整理摘要及语义记忆。新请求、停止、关闭窗口和新对话会取消旧维护；会话 ID 与记忆代际检查阻止过期结果写回。失败保留原文及待处理位置。摘要和记忆整理使用当前配置的模型 API，会额外计费。

消息记录发送时的 UTC 时间，模型接收含时区的原消息时间；“明天/下周”以说话当时为准。旧记录没有时间时明确未知。近期纠正优先于旧摘要/记忆；较早证据不能覆盖较新的明确记忆。

存储位于当前用户 LocalApplicationData/AnnaDesktopPet：chat-gpt.bin / chat-deepseek.bin、各自 chats-* 归档、memory-v2.bin。旧 memories.bin 按需兼容迁移。文件损坏尝试恢复备份；无法恢复时阻止覆盖并在界面提示。完整会话文件上限 64 MiB，超限明确保存失败，不静默截断。发布包不得包含上述个人数据。

## 验证

在项目根目录执行：

```powershell
& '.\杏菜桌宠\source\run-context-tests.ps1'
& '.\杏菜桌宠\source\run-general-context-tests.ps1'
& '.\杏菜桌宠\source\run-conversation-store-tests.ps1'
& '.\杏菜桌宠\source\run-semantic-memory-tests.ps1'
```

离线测试覆盖两种模型请求适配、真实 WPF 发送方法、完整记录/摘要恢复、新会话归档、错误及取消、未摘要的纠正、原消息时间、模型提议校验、加密及遗忘屏障。使用合成文字和隔离目录，不修改真实用户记录。

真实模型验证为 opt-in：`run-live-general-context-tests.ps1 -RunLive -Provider DeepSeek`。测试姓名指代、长对话后的话题返回、最新纠正、选择前项和无依据时澄清，不操作 QQ 音乐。少量实测不能等同于所有对话的准确率；GPT 与 DeepSeek 共用实现，但各模型质量需分别验证。

2026-11-09 验证结果：普通上下文回归两版各 208 项、原点歌回归 GPT 217 / DeepSeek 216 项、加密存储两版各 46 项、语义记忆 84 项通过。两版 v1.39 编译与完整桌宠自检通过。DeepSeek 实网普通承接 7 例通过（含“他后来呢”“不是这个，我说的是前一个”）；另加 `-Maintenance` 的 4 例检查真实摘要、隐含偏好、明确纠正和普通聊天路由，通过。实网曾检出推断喜好被误标确定及内部时间标签泄漏，已增加本地防护与回归。GPT 本次未做实网验证，不以离线测试代替语义质量结论。
